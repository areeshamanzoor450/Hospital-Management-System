# Hospital Management System

A desktop-based Hospital Management System developed in **C# Windows Forms** using **.NET Framework 4.7.2**. The application provides a centralized interface for managing hospital operations, including patients, doctors, appointments, diagnoses, and inventory.

## Features

- **Login System** – User authentication interface.
- **Patient Management** – Manage patient records.
- **Doctor Management** – Maintain doctor information.
- **Appointment Management** – Manage hospital appointments.
- **Patient Appointments** – View and manage patient appointment records.
- **Diagnosis Management** – Handle patient diagnosis records.
- **Inventory Management** – Manage hospital inventory.
- **Home Dashboard** – Main interface for accessing system modules.

## Technologies Used

- C#
- Windows Forms
- .NET Framework 4.7.2
- Microsoft Visual Studio
- ADO.NET
- System.Data.SqlClient

## Getting Started

1. Install Microsoft Visual Studio.
2. Install the .NET Framework 4.7.2 Developer Pack.
3. Clone or download this repository.
4. Open `pf project.sln` in Visual Studio.
5. Restore the required NuGet packages if needed.
6. Build and run the project.
